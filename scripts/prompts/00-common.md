## 何を作っているか

**危険物取扱者試験 乙種第 4 類**（一般財団法人消防試験研究センターが実施）**の学習アプリの教本**です。
問題集アプリではありません。**「通読できる教本」が最優先の要件**で、演習機能より教本の質を優先します。

まず `CLAUDE.md` を読んでください。ここに書いていない方針はすべてそこにあります。

**出題範囲は `docs/syllabus.md` にあります。**この試験には公表されたシラバスが無いので、
消防法・政令・規則と、消防試験研究センターの公開問題 35 問から自前で起こしたものです。
**あなたの担当する節がどの項目に当たるかは、章のプロンプトに書いてあります。**

## この試験に固有の 4 つの要求

### 1. 数字をごまかさない

**この試験は数字そのものを問います。**指定数量、引火点、発火点、燃焼範囲、保安距離、
保有空地の幅、タンクの容量。

**`docs/primary-numbers.md` を必ず開いてください。**一次資料と突き合わせた数値の台帳です。

- **A 節（法令から取った値）は断定して書いてよい。**「10 m 以上である」と書けます
- **B 節（物性値）は断定しないでください。**
  出典によって値が違います（アセトンの引火点は消防庁 −18 ℃、厚労省 SDS −20 ℃）。
  **「−20 ℃前後」「常温より低い」という向きで書いてください**
- **B 節の表にある † は「消防庁のデータベースに項目が無い」という印です。**
  **記憶や他の教材で埋めないでください。**
- **台帳に無い数字を書かないでください。**どうしても要るなら、本文に書くのではなく
  報告に「この値が要る」と挙げてください

**「およそ」「〜程度」で逃げるのも禁止です。**台帳の値をそのまま使うか、書かないかのどちらかです。

### 2. 法令の条文は、要件を全部並べる

**系譜で繰り返し出ている誤りが「条文の要件の書き落とし」です。**
「A または B」を「A」とだけ書く、「ただし〜を除く」を落とす、といった型です。

- 条文を要約するときは、**「または」「かつ」「〜を除く」を落とさない**こと
- 例：**特殊引火物の定義は「発火点 100 ℃以下、**または**引火点 −20 ℃以下かつ沸点 40 ℃以下」**です。
  **「かつ」でつなぐと誤りになります**
- 条番号を書くなら、`docs/primary-numbers.md` に載っているものだけにしてください。
  **記憶で条番号を書かないこと**（このリポジトリでも実際に間違えました）

### 3. 科目の線引きを守る

**燃焼と消火の理論は、物化（`sci-burn` / `sci-stop`）と性消（`prop-common`）の
どちらでも扱います。**範囲の重複ではなく、**問われ方が違う**だけです。

| | 物化で扱う | 性消で扱う |
| --- | --- | --- |
| 燃焼 | 燃焼とは何か（定義・3 要素・形式） | この物質はなぜ燃えやすいか |
| 引火点 | 引火点・発火点・燃焼点の違い | ガソリンの引火点はどれくらいか |
| 消火 | 消火の 4 要素、消火剤の原理 | この火災にこの消火剤は使えるか |

**同じ用語を章によって違う説明にしないでください。**用語の定義は物化の側に合わせます。

### 4. 「法令を捨てて他で稼ぐ」と読める書き方をしない

**この試験は科目ごとに 60 % 以上が必要で、1 科目でも 6 割を切れば不合格です。**
合計点ではありません。

「ここは配点が低いので飛ばしてよい」「苦手なら捨ててよい」という書き方をしないでください。
**捨てられる科目はありません。**

## 節の骨格

1 つの節は、次の形で書いてください。**この書式は `src/lib/digest.ts` が
直前チェックシートへ機械的に抜き出します。崩すと拾われません。**

```
# ざっくり言うと
（日常語で「何の話か」。3〜5 行）

（本論。見出し・表・図）

> **試験のポイント** …（暗記すべき事項）
> **よくある勘違い** …（先回りして潰す誤解）

# この節のまとめ
- （箇条書き 5〜6 個）

（一問一答ブロック）
```

- **`# ざっくり言うと` と `# この節のまとめ` は必須です。**文言を変えないこと
- **`> **試験のポイント**` は各節に 1 つ以上。**行頭の `> ` と `**…**` の形を崩さないこと
- **`> **よくある勘違い**` は、本当に勘違いであるものだけに使ってください。**
  事実の再掲を「よくある勘違い」として書く誤りが系譜で繰り返し出ています。
  **「◯◯だと思われがちですが、実は△△です」**の形になっているか確かめること

## 一問一答は厚めに

**本番は 35 問を 120 分（1 問あたり約 3 分 26 秒）で解く試験です。**
時間には余裕があるので、**速さより「数字を覚えているか」で決まります。**

**指定数量・引火点・保安距離・保有空地の幅・危険等級は、一問一答向きの題材です。**
各節の末尾に、次の形で **5 問以上**（できれば 6〜8 問）置いてください。

- 1 行 1 問。`問い :: 答え` の形
- 問いも答えも 1 行に収める（改行しない）
- 答えは、その場で声に出して言える長さにする
- **問いの中に `::` を使わない**
- **数値を問う一問一答を厚めに。**「第 1 石油類（非水溶性）の指定数量は :: 200 L です」の形

使えるのは次だけです。**それ以外の Markdown 記法は動きません。**

- 見出し `#`（節内の大見出し）/ `##` / `###`

- 表（`| a | b |` と区切り行 `| --- | --- |`）
- 引用 `> `（試験のポイント・よくある勘違いに使う）
- 強調 `**…**` / コード表記 `` `…` ``

- 水平線 `---`
- 行内数式 `$…$` は使えますが、**この試験の計算は四則演算が中心なので、
  ほとんど使う場面がないはずです。**使いたくなったら、たいてい説明が難しすぎます

**表を厚く使ってください。**この試験は「値の対応表」が知識の本体です。
指定数量の表、保安距離の表、消火設備の適応表は、**文章より表のほうが読者の役に立ちます。**

### 図

```` ```diagram:種類 ```` で図を書けます。使える種類は
`flow` `stack` `tree` `matrix` `cycle` `seq` `bits` `compare` の 8 つです。

- `キー: 値` の行は指示子（`title` `top` `bottom` `x` `y` `note` `actors` `caption`）
- それ以外の行が要素。`ラベル :: 補足` で**補足**を付けられる
- `tree` はインデント 2 スペースで 1 段のネスト
- `stack` は**先頭が最も幅広い**。上下の向きが意味と合っているか確かめること
- `seq` は `A -> B :: 内容` の形で書く。**矢印が無いと `::` の右が黙って消えます**
- **図の中では `**強調**` が効きません。**アスタリスクがそのまま画面に出ます
- **図の題に「N つ」と書いたら、要素の数を N 個に合わせてください。**検査が数えます
  （漢数字も数えます）

#### `compare` の書き方（**系譜で 4 回壊しています**）

`compare` は **「1 行 1 セル、偶数行が左・奇数行が右」**です。
**`::` は左右の区切りではありません。**

正しい書き方：

```
title: 運搬と移送
actors: 運搬 | 移送
容器に入れて車両で運ぶ
移動タンク貯蔵所で運ぶ
指定数量未満でも基準がかかる
指定数量にかかわらず基準がかかる
危険物取扱者の同乗は要らない
危険物取扱者が乗車する
```

**やってはいけない書き方**（`::` は補足であって左右の区切りではないので、意味が壊れます）：

```
容器に入れて車両で運ぶ :: 移動タンク貯蔵所で運ぶ
```

**要素の数が偶数だと検査を素通りします。**書いたあと、左右が正しく対になっているか
目で確かめてください。

**図は「本文で説明したことを整理する」ために使ってください。**
図に本文と違うことを書かないこと（姉妹アプリで実際に食い違いが出ました）。
**本文からソースの行番号を指さないでください。**

バックスラッシュが落ちます。**姉妹アプリで何度も壊しました。**

## 名指しで釘を刺しておくこと

**系譜では、名指しした箇所は全章で正しく書けていました。**下の 8 つは必ず守ってください。

1. **特殊引火物の定義は「または」**。「発火点 100 ℃以下**かつ**引火点 −20 ℃以下」は誤り
2. **気体は危険物ではない。**プロパン・水素・アセチレンは高圧ガス保安法の側
3. **保安講習は「3 年に 1 回」ではない。**起点が「受講日以後における最初の 4 月 1 日」なので、
   実際の間隔は 3 年を超えます
4. **仮貯蔵・仮取扱いは「許可」ではなく「承認」**。しかも**消防長または消防署長**であって、
   市町村長等ではありません
5. **予防規程は「届出」ではなく「認可」**
6. **水は棒状でも霧状でも第 4 類に効かない。**効くのは**霧状の強化液**です。
   **棒状の強化液は効きません**
7. **ガソリン・灯油・軽油・重油は混合物**であって、化合物ではありません。
   **だから引火点や沸点に幅があります**
8. **引火点が低いほど危険**です。「引火点が低い＝燃えにくい」と読める書き方をしないこと
