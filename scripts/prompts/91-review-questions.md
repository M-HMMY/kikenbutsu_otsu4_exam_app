## いちばん大事なこと

**この試験は四肢択一で、1 問あたりちょうど 60 秒です。**
だから最大の論点は、**「正解が本当に 1 つに定まるか」**です。

**「問題に不備はありませんでした」という報告を書かないでください。** 姉妹アプリでは、同じ作り方をした確認問題 334 問に別の目を入れて **94 件**の指摘が出ました。自己レビューでは 0 件でした。**必ず何かあります。**

## 何を見るか（この順に）

### 1. 正解が 1 つに定まるか（最優先）

**1 問ずつ、4 つの選択肢すべてについて、正しいか誤りかを自分で判定してください。**

- **誤答が、実は正しくないか。** **最も重大な型です。**言い切りすぎて誤答にしたつもりが、実際には正しかった、という例が繰り返し出ています
- **正解が、実は誤りでないか**
- **正解が 2 つ以上あることにならないか。** 選択肢の書き方によっては両方成り立つことがあります
- **分類の軸が混ざっていないか。** 誤答が正解と別の軸の言葉で書かれていると、両方成り立ってしまいます
- **前提条件が書かれているか。** 「時点」「どの文書の原則か」「どの法律の話か」が書かれていないと答えが定まらない問題がないか

### 2. 解説

- **4 つの選択肢すべてに触れているか。** **誤答の説明もれは、系譜で最も多い型です。**言い換えて触れている場合は「触れている」と数えてください
- **なぜ誤りなのかが書かれているか。** 「誤り」とだけ書いて理由がないものは指摘してください
- **解説の内容が、教本の該当節と食い違っていないか**
- **`sectionId` が設定されているか。** また、**その節が本当にその問題の内容を扱っているか**

### 3. 選択肢の作り
- **正解だけが突出して長くないか。** 読まずに「長いものを選ぶ」で当てられてしまいます
- **「必ず」「すべて」「一切」といった言い切りが、誤答にだけ出ていないか。** 言い切りが誤答側にしか現れないと、それ自体が手掛かりになります
- **正解の位置が偏っていないか**（担当範囲の中での分布を数えてください）。**ただし、数値や順序が選択肢になっている問題は並べ替えられません。**その場合は指摘しないこと
- **かっこ書きの言い換えが、本当に同義語か。** 同義語だと思って添えた語が、実は別の意味の専門用語だった、という例があります

### 4. 問題文

- **60 秒で読んで答えられる長さか。** 空白を除いて 120 字を超えるものは挙げてください
- **問題文の中に答えが書かれていないか**
- **教本を読んでいれば答えられるか。** 教本にまったく書かれていない事項を問うていないか

### 5. 範囲と重複

- **シラバスの範囲外を問うていないか。** `docs/syllabus-2026-02.md` に詳細キーワードまたは学習項目があるかで判定してください。**判断に迷ったら、指摘として挙げたうえで「範囲外かもしれない」と添えてください。採否はこちらで判断します**
- **章をまたいだ重複がないか。** 担当範囲の中だけでなく、**他の章のファイルも読んで、同じことを問う問題がないか確かめてください**。1 節ずつ見ている限り気づけない型です
- **数式を要求する問題がないか。** **この試験に数式は出ません。1 問でもあれば指摘してください**

### 6. この試験に固有の観点

- **英略語の正式名称を問う問題で、正式名称の綴りと語の並びが正しいか**
- **モデル名・サービス名を問う問題に、時点の前提が要らないか。** 「〜が最も高性能」のように時点で変わる事柄を問うていないか
- **提供元の対応**（Gemini＝Google、Claude＝Anthropic、Copilot＝Microsoft、Sora＝OpenAI、Veo3＝Google）が正しいか
- **原則の一覧を問う問題で、「どの文書の原則か」が明示されているか。** 基本理念・AI 社会原則・共通の指針は**別の文書で数が違います。**文書を書かずに「AI 社会原則に含まれないものはどれか」と問うと、答えが定まりません

## 報告の形

**指摘 1 件ごとに、次の形で書いてください。**

```
[確信度: 高 / 中 / 低] 問題 id
種類: 正解が定まらない / 誤答が実は正しい / 解説の欠落 / 範囲外 / 重複 / その他
何が問題か: 
どう直すか: 
```

- **「正解が定まらない」型を先に**並べてください。次に解説の欠落、そのあとに表現の問題
- **1 件ずつ独立させてください**
- **ファイルを書き換えないでください。** 指摘だけを報告してください
- 最後に、次の 2 つを付けてください
  1. 担当範囲の**正解の位置の分布**（ア / イ / ウ / エ の数）
  2. **問題がなかった問題 id の一覧**（何を見たかが分かるように）
