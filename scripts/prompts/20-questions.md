## 試験の形（問題の作り方を決める前提）

- **五肢択一式。35 問を 120 分（1 問あたり約 3 分 26 秒）。**
  **四肢択一ではありません。選択肢は 5 つです**
- **時間には余裕があります。**読み切るのが精一杯ということはないので、
  **条文を読ませるやや長い問題も成立します**
- **計算が出るのは物化だけ**です。しかも**試験会場で電卓が使えない**ので、四則演算に限ります
- **落とすとしたら数字と、似た制度の取り違えです。**
  指定数量・引火点・保安距離、そして「許可か承認か認可か届出か」

## 1 問の作り方

```ts
{
  id: 'law-what-q01',
  categoryId: 'law-what',
  sectionId: 'lw-3',
  question: '…',
  choices: ['…', '…', '…', '…', '…'],
  answer: 2,
  explanation: '…',
  level: 2,
},
```

- **`id` は `<章 ID>-q01` から連番。**ゼロ詰め 2 桁
- **`sectionId` は必ず付けてください。**解説から教本へ戻る導線と、節ごとの出題に使います。
  **その問題の内容を実際に扱っている節**を指すこと
- **`choices` は 5 要素。**型が 5 要素のタプルなので、4 つだと型エラーになります
- **`answer` は 0〜4**（0 が 1 番目、4 が 5 番目）
- **`level` は体感難易度 1（易）〜3（難）。**1 と 3 を偏らせず、2 を中心に散らしてください
- **`source` は設定しないでください。**公開問題の収録は依頼した側が別に行います

## 守ること

### 問題文

- **空白を除いて 200 字以内。**`npm run check` が 200 字で注意、300 字でエラーにします
- **問題文の中に答えを書かないこと**
- **教本に書かれていることだけを問うこと。**教本にない事項を問わない
- **「法令上」で始める問題を混ぜてください。**本番の法令科目はほとんどがこの形です

### 選択肢

- **5 つ。重複させない**
- **正解の位置を散らすこと。**五肢択一なので、**ならせば各 20 %** です。
  **書き終えたら、0〜4 の数を自分で数えて、報告に書いてください**
- **誤答も正解と同じ密度で書くこと。**
  **正解だけが長いと、読まずに「長いものを選ぶ」で当てられます。**5 つの長さをそろえてください。
  検査は「正解が 24 字以上・最長の誤答の 1.3 倍以上・差 6 字以上」を注意にします
- **「必ず」「すべて」「常に」「一切」を誤答専用にしないこと。**
  言い切りが誤答側にしか出てこないと、それ自体が手掛かりになります。
  **正解の選択肢にも、正しく言い切れる場面では使ってください**
  （例：「移送のためには**常に**危険物取扱者が乗車しなければならない」は正しい言い切りです）
- **誤答は「もっともらしい」ものにすること。**同じ章に出てくる別の値・別の制度を使うのが基本です
  （指定数量の問題の誤答に、他の品名の指定数量を置く、など）
- **分類の軸を混ぜないこと。**5 つの選択肢が、同じ軸の上に並んでいること

### 解説

- **正解の理由だけでなく、誤答がなぜ誤りかにも触れること。**
  **5 つすべてに触れてください。**「誤答の説明もれ」は系譜で最も多い型です
- **数字を訂正する解説では、正しい値を書くこと。**「200 L ではない」で終わらせず「400 L である」まで書く
- **試験テクニックを教えないこと。**
  「『必ず』と言い切った選択肢を疑ってください」のような解説は書かないでください。
  **内容の説明に書き換えること**
- 解説の内容が、**教本の該当節と食い違わないこと**

### 章をまたいだ重複

- **同じことを問う問題を、別の節で作らないこと。**
  `npm run check` が、選択肢まで含めた類似度で検出します
- **担当章の中でも、対比のために対で作る場合を除いて、似た問題を並べないでください**
- **ただし「数値だけ違う問題」は重複ではありません。**
  指定数量の倍数の計算を、値を変えて複数出すのは意図した繰返しです

## 設問の形は本番の比率に寄せる

**本番 35 問の内訳はこうでした**（`docs/public-questions.md`）。

| 形 | 本番 | あなたの担当 |
| --- | --- | --- |
| **誤っているもの / 妥当でないもの / 該当しないもの**を選ぶ | **22 問（63 %）** | **6 割前後に** |
| **正しいもの**を選ぶ（穴埋め・計算を含む） | 12 問（34 %） | 3 割強 |

**「正しいものを選ぶ」ばかりにしないでください。**本番と手応えが変わります。

**「誤っているものはどれか」の形では、選択肢 5 つのうち 4 つが正しい記述**になります。
**その 4 つも、教本の内容と矛盾しない、読んで勉強になる記述にしてください。**

## この試験に効く出題の型

**数字と、似た制度の取り違えで落とす試験なので、次の型を厚めに入れてください。**

1. **数値をそのまま問う** … 「第 2 石油類（水溶性）の指定数量として、正しいものはどれか」。
   **誤答には他の品名の指定数量を置く**
2. **手続の種類を問う** … 「法令上、予防規程について必要な手続として正しいものはどれか」
   （許可・承認・認可・届出・不要 を並べる）
3. **組合せを問う** … 「保安距離を保たなければならない施設の組合せとして正しいものはどれか」。
   **本番で 3 問出た形です**
4. **該当しないものを問う** … 「第 4 類の品名に該当しないものはどれか」。
   **他の類の代表物質を混ぜる**のが定番
5. **向きを逆にした誤答** … 「沸点は外圧が高くなると低くなる」のように、
   **正しい記述の向きだけを裏返す**
6. **物質の性状を問う** … 「◯◯の性状として、誤っているものはどれか」。
   **色・臭い・比重・水溶性・引火点を並べ、1 つだけ裏返す**

> **性状の問題で「無臭」と書くときは注意してください。**
> 第 4 類はほとんどが有臭で、**「無色無臭」は誤答の定番**です。
> **本当に無臭なのはグリセリンとエチレングリコールくらい**です（`docs/primary-numbers.md` B-5）。

## 数字を書くときの決まり

- **`docs/primary-numbers.md` の A 節（法令の値）は断定してよい。**「10 m 以上」と書けます
- **B 節（物性値）は断定しないでください。**出典によって値が違います。
  **「−20 ℃前後」「常温より低い」という向きで問うこと**
- **B 節の表の † は「出典に項目が無い」印です。**その値を問う問題を作らないでください
- **台帳に無い数値を問う問題を作らないでください**

## バックスラッシュの落とし穴

TypeScript の文字列の中に書くので、次のエスケープが要ります。

| 書きたいもの | ファイルに書く形 |
| --- | --- |
| `\n` を文字として出す | `\\n` |
| バッククォート（テンプレートリテラル内） | バックスラッシュ + バッククォート |
| `$` + `{`（テンプレートリテラル内） | バックスラッシュ + `$` + `{` |

**bash のヒアドキュメント（`cat > file <<'EOF'`）は使わないでください。**バックスラッシュが落ちます。
ファイルの編集は、エディタ相当の書き込み（apply_patch 等）で行ってください。
