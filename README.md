# 危険物乙4 学習アプリ

**危険物取扱者試験 乙種第 4 類**の学習アプリです。教本・確認問題・間隔反復・模試を 1 つにまとめてあります。

**まだ足場だけです。**教本も問題も入っていません。

## 試験の形

**2026 年 9 月 13 日に[消防試験研究センター](https://www.shoubo-shiken.or.jp/kikenbutsu/)で確認した内容です。**要項は改訂されるので、受験の前に公式サイトで確かめてください。

- **五肢択一式**のマークカード方式、**35 問 / 2 時間**
- 科目は **法令 15 問 / 物化 10 問 / 性消 10 問**
- **合格基準は、科目ごとにそれぞれ 60 % 以上。**合計点ではありません
- 受験資格なし、受験手数料は乙種 5,300 円
- **実施は都道府県ごと。**日程は受験する県の支部の案内で確かめてください

## 動かす

```
npm install
npm run dev      # 開発サーバ
npm run check    # データの整合性 + 実際に描いてみる検査
npx tsc --noEmit
npm run build
```

デスクトップから起動するショートカットを作る場合：

```
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\make_shortcut.ps1
```
